# Higgsfield generation request form

Copy and fill in the blanks. If a `[required]` item is empty, do not proceed on assumptions — ask before running.

```
[Model] Soul 2.0 / Soul Cinema / Seedance 2.5 (pick one) [required]
[Purpose] product ad / portrait / thumbnail / social / other: [required]
[Subject] (one line: what is being shown) [required]
[Key elements] (people, product, place, props) [required]
[Style] (cinematic, Y2K, studio, photoreal, … + optional preset)
[Format] image: ratio (9:16 / 1:1 / 16:9 …) / video: length, resolution, ratio [required]
[References] (files + role: identity / product / camera / palette)
[Soul ID] (name if used / none)
[Audio — video only] dialogue, effects, ambience, music
[Budget cap] (USD) [required: if none, state that estimate approval replaces it]
[Avoid] (omit if none)
```
