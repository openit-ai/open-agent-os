WHY OPEN AGENT OS?

Yours, not rented.

Your agent lives on your hardware — a mini PC at home, a VPS for your team, your company's server. Conversations, files, and knowledge stay there. No per-seat cloud pricing, no data leaving your premises, no service you cannot walk away from.

One URL is the whole setup.

The bootstrap is a conversation. The agent reads the repository, explains your options, runs the installation, verifies every step with real checks, and hands you a working system. You never paste a command you do not understand.

Enterprise capability at indie cost.

The Personal edition runs on an N100-class mini PC with a low-cost flat LLM plan (≈ $10/month). The tools you already use get connected, not replaced. No new subscriptions.

A second brain that compounds.

Every conversation, document, and decision can be filed into your own wiki, and the agent maintains the cross-references and consistency. Unlike a stateless chatbot, your context accumulates into an asset — and the asset stays yours.

Start small, never re-platform.

Personal → Project → Company on one core. Begin with yourself; add teammates, shared knowledge, and governance when you are ready. Same skills, same files, same agent — just more of them.

Safe by design, governed at scale.

Destructive actions need your approval. Secrets live in one protected place and are never echoed. At company scale you get policy, audit, and admin controls — from a platform that already runs in production.

COMPUTER USE

Computer use — the agent's hands

The agent doesn't just answer — it can operate the browser and applications on the machine where it runs.

  • Hangul (HWP) documents — drafts form-based HWPX documents such as grant applications, proposals, bids, and official letters; you do the final polish in your own office suite.
  • Work portals — automates login and repeated entry on accounting, tax, and ERP sites. Public certificates stay in your local vault; signing and submission run only after approval.
  • Government paperwork — from application through payment, issuance, saving, and a wiki record. Payment steps pause for your approval.

Risky actions — payments, sending, deletions — always pass through your approval first. Credential typing stays vault-only by default.

QUICK START

Quick start — "One URL"

  1. Install Hermes Agent — official installer.
  2. Tell it this repository — e.g. "set up openit-ai/open-agent-os".
  3. Follow the agent — README → START-HERE → installs the oaos-bootstrap skill.
  4. Pick an edition — Personal / Project / Company.
  5. Pass the gates (3–6) — click links, choose options, paste keys or tokens; each is verified on the spot.
  6. Verify and report — services, responses, files, wiki, and schedules checked end-to-end.

The agent does the reading, the file edits, and the commands. You only handle the gates.

SKILLS

Skills — how it grows

Core skills ship with Open Agent OS as plain SKILL.md packages, installable with Hermes. Add MCP servers and skills, and the agent gains capabilities without changing the core.

  • oaos-bootstrap — the bootstrap orchestrator: environment check → edition selection → setup → gates → verify → report.
  • oaos-ops — day-2 operations: health checks, backups, updates, restores, log inspection.

Optional extension skills (bring your own API keys):

  • promo-video-generation — 20-second promo videos for a place: chat interview → live-action images → shot script → generation. Quote-and-approve before every run.
  • higgsfield-media-generation — image and video generation helper with cost estimates built in.
  • figma-design-generation — design inside Figma from chat: screens, components, diagrams, design-to-code handoffs.
  • naver-cafe-manager — keyword monitoring with alerts, draft-first post writing, comment review and replies.
  • naver-blog-manager — new-post watching, draft-first writing, a collection pipeline that saves articles as markdown with original-resolution images.
  • sketchup-design-generation — exact-dimension 3D models from chat with SKP / PNG / STL exports.
  • vps-youtube-content — fetch YouTube transcripts on a VPS with a cheapest-first recovery ladder.

HARNESS & CONFIGURATION

Your agent's identity is plain markdown

The agent's identity and memory are markdown files on your machine — you can read, edit, and version them.

  • SOUL.md — the persona and working principles you define.
  • USER.md — your profile; the agent maintains it automatically from your conversations.
  • MEMORY.md — the agent's own notes; written by the agent, correctable by you.
  • AGENTS.md — per-project instructions for team and company workspaces.

Settings, secrets, skills, and schedules complete the surface — with templates and a seeding guide so your agent starts with a sane, personal harness instead of a blank one.
